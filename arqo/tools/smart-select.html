Smart Select

Select everything in the current context that is like the reference: same component, definition family, material, size, shape, tag, axis or inside its bounding box. Criteria combine, sets of them are saved and reused.

How to use it

  1. Select the reference object(s) in the model and open Smart Select; the panel shows the reference.
  2. Tick one or more criteria under Match; the live count shows how many match.
  3. Under Options, choose what to select, the size tolerance and whether hidden items count.
  4. Choose New selection or Add to selection, then click Select.
  5. Save… stores the ticked criteria as a named set; pick it later from Saved sets.
  6. Select something else in the model, or click Use selection, to change the reference.

Type in the measurements box

1
Size tolerance field: sizes may differ by 1 %

Good to know

  • Ticked criteria combine: an item must pass all of them.
  • Only the context you have open is searched.
  • Hidden items, and items on hidden tags, are left out unless Hidden too is ticked.
  • Size, shape and box come from the geometry only; text or dimensions inside do not count.
  • The selection the panel makes does not replace the reference, so you can change the criteria and select again.
  • Nothing in the model changes; selecting is not an undo step. Up to 30 sets can be saved.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
