Line Tool

Lines, guide lines and points; arithmetic in the length box and x,y,z input.

Pictures and a short film of Line Tool at work come here.

How to use it

  1. Start the Line Tool; press Tab to choose Line, Guide line or Guide point.
  2. Click the start, or type a point such as [0,0,0] and press Enter.
  3. Click the end, or point the mouse the way the line goes and type a length.
  4. Keep clicking: each line starts where the last one ended.
  5. Press Esc to end the chain; closing back on the first point ends it too.

Keys

Tab
Next mode: line, guide line, guide point
Shift (hold)
Locks the current direction
Arrows
Lock the direction to an axis
Esc
Ends the chain, then leaves

Type in the measurements box

1200
A line 1200 long in the mouse's direction
1200+300
A sum: 1500
3000/4
A division: 750
2*600
A product: 1200
1.2m-150mm
Mixed units
[1000,2000,0]
A point in the model's axes; before the first click it sets the start
<500,0,0>
A point measured from the last point
[1000;2000;0]
The same point where the decimal mark is a comma

Good to know

  • A guide point is one click each.
  • A loop closed in one plane makes a face, as SketchUp's own Line tool does.
  • Each line is its own Undo step, as in SketchUp.
  • Draws in the group or component that is open. The chosen mode is remembered.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
