Reference Scale

The two-point way into Smart Scale: click two points on the selection, type the distance they should have, and everything is scaled about the first point. For imported drawings and models of unknown scale.

Pictures and a short film of Reference Scale at work come here.

How to use it

  1. Select what to scale, such as an imported drawing or model.
  2. Start Reference Scale (Extensions › ARQO for SketchUp): the Smart Scale panel opens and waits for two points.
  3. Click two points whose real distance you know; the distance so far is shown while you pick.
  4. In the panel, type the distance they should be apart and press Scale (or Enter).

Keys

Esc
while picking the points: cancel
Enter
in the distance field: Scale

Type in the measurements box

5000mm
the two points end up 5000 mm apart
=5000
5000 in the model's unit
x2
twice as large

Good to know

  • Everything selected is scaled uniformly about the first point.
  • A bare number is refused: add the unit or =.
  • Locked objects are left as they are. One Undo removes the scaling.
  • Inside an open component placed more than once, it asks first.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
