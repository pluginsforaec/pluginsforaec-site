Tag Tools

Assign a tag (new or existing) to the selection, untag raw geometry inside groups and components, isolate or hide the selection's tags, step through tags one at a time, make a tag current, select by tag and remove unused tags.

How to use it

  1. Select something in the model and open Tag Tools; the list shows every tag, its visibility and how many selected items carry it.
  2. Assign: click a tag or type a name (new or existing), tick Nested geometry too if needed, click Assign.
  3. Set to Untagged clears the selection's tag; Untag inside clears only the raw geometry inside selected groups.
  4. Visibility: Isolate or Hide the selection's tags, step with Previous / Next, or turn All on.
  5. Click a tag, then Select by tag or Make current; Remove unused deletes tags nothing uses.

Good to know

  • Isolate, Hide, All on, Previous / Next, Make current, Set to Untagged and Remove unused are also in the Extensions › ARQO for SketchUp menu, so they can get a keyboard shortcut.
  • Assign with nested geometry and Untag inside reach into groups and components: for a shared component, only the selected copies change unless you choose All copies.
  • Isolate keeps the tags used inside the selected groups visible too; the active tag always stays on.
  • Select by tag works in the open context and picks only what is visible. Make current needs a selection with one tag.
  • Remove unused never removes Untagged or the active tag. All on turns tag folders on too.
  • Each action is one Undo, except Make current (not an undo step in SketchUp). Locked groups are kept and counted.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
