Import Camera

Bring the camera and two-point perspective from another SketchUp file.

Pictures and a short film of Import Camera at work come here.

How to use it

  1. Start Import Camera.
  2. Choose the .skp file whose views you want.
  3. Under View, pick the file's current view, one of its scenes, or every scene.
  4. Under Do, choose Set this view or Add it as a scene.
  5. Confirm; the message lists what was set or added.

Good to know

  • Each view comes with its eye, target, up direction, projection and field of view (or a parallel view's height).
  • Every scene is always added as new scenes; when you add scenes, your own view comes back afterwards.
  • A scene name already in the model gets a number: Name (2), Name (3).
  • A two-point perspective's 2D shift cannot be set by an extension: that view comes level and unshifted, and the message says so.
  • Setting the view or adding scenes is not an Undo step in SketchUp: delete unwanted scenes in the Scenes panel.
  • The open model itself cannot be chosen; a file that cannot be read changes nothing.
  • Windows only for now.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
