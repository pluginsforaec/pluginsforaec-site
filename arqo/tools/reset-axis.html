Reset Axis+

Put a group's or component's axes back on its geometry: X on the longest edge, origin at the lower corner; nothing moves in the model.

How to use it

  1. Select one or more groups or components.
  2. Run Reset Axis+.
  3. If a selected component has other copies, choose Selected only or All copies.
  4. Read the report: how many were reset, already aligned or skipped.

Good to know

  • The red X axis is turned onto the longest horizontal edge inside the object; blue Z stays vertical.
  • The origin moves to the lower corner of the geometry in the new axes.
  • If the object has no edges of its own, the edges of the groups inside it are used.
  • Shared components: by default only the selected copies change (they get their own definition); all copies only if you choose it.
  • Locked objects and objects without edges are skipped and counted. One Undo reverses it all.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
