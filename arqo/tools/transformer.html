Transformer

Scale, move, rotate and colour groups and components.

Pictures and a short film of Transformer at work come here.

How to use it

  1. Select groups or components and run Transformer; a box opens.
  2. Type moves along X, Y, Z, turns about X, Y, Z in degrees, and scales along X, Y, Z.
  3. Choose the pivot (centre or base), the axes (the object's own or the world's) and each object alone or all together.
  4. Optionally pick a colour: keep, no colour, or a material of the model.
  5. Confirm: scale is applied first, then the turn, then the move.

Type in the measurements box

500mm
Move field: 500 mm along that axis
1200+300
Move field: the sum, 1500 in the model's units
90
Turn field: 90 degrees
-45
Turn field: minus 45 degrees
2
Scale field: twice the size (x2 works too)
50%
Scale field: half the size

Good to know

  • Empty fields change nothing; if nothing would change, the box stays open and says so.
  • Moves and turns start at 0 and scale at 1 each time; pivot, axes and each/together are remembered.
  • A turned object is scaled along its own axes and never sheared; the report counts them.
  • Locked objects are left alone and counted; if all are locked, nothing changes.
  • The colour list shows up to 40 materials of the model. One Undo takes it all back.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
