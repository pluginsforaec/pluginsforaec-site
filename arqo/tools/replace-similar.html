Replace Similar

Select one component and run Replace Similar: every component like it is replaced by the one chosen in the box, each keeping its place, turn, scale, material and tag. Like it: the same component (every copy), the same size (its box within 1 mm, any component) or the same name ("Chair", "Chair#2"). Copies inside groups too. One Undo.

Pictures and a short film of Replace Similar at work come here.

How to use it

  1. Select one component.
  2. Click Replace Similar.
  3. In the box: the component to put in, and what makes one similar (same component, same size, same name).
  4. Every similar one is replaced; the message says how many.

Good to know

  • Same size compares the boxes within 1 mm: a different component of the same size is replaced too.
  • Copies inside groups are found as well.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
