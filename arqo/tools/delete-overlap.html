Delete Overlap

Remove group and component copies that sit on the same spot, in the selection or the whole model.

How to use it

  1. Select the groups and components that may overlap (Select All is fine).
  2. Click Delete Overlap (toolbar, or Extensions › ARQO for SketchUp › DOCTOR).
  3. Read the message: duplicates removed, copies kept, and look-alikes that were kept because their data differs.

Good to know

  • A duplicate is the same geometry in the same place (every point within 0.01 mm) with the same tag, material, shadow settings, hidden state and attributes. Names and descriptions do not count.
  • Look-alikes that carry different data are kept and counted.
  • The first of each set is kept and the rest are erased; nothing is moved or merged.
  • Only the selected groups and components are compared; loose edges and faces are not checked.
  • Locked groups and components are skipped and counted.
  • One Undo brings every removed copy back.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
