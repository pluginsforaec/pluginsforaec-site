Weld+

Join edges into a curve or a set of curves.

How to use it

  1. Select the edges to join, or a face to use its outline.
  2. To weld edges inside a group or component, double-click it to open it first.
  3. Run Weld+.
  4. Read the report: curves made, and what was left alone and why.

Good to know

  • Edges that meet end to end form a chain; a free end or a branch of three or more edges ends it.
  • A chain through an existing arc or curve is not welded, so the arc keeps its centre and radius; explode that curve first if you want one curve.
  • Edges that are already one curve, single edges and branches are left as they are and reported.
  • Closed groups and components in the selection are not entered.
  • No edge is created, moved or deleted. One Undo reverses it.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
