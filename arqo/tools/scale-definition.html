Scale Definition

The selected groups' and components' scale goes into their definitions; every other copy keeps its size. Reported in the Smart Scale panel.

How to use it

  1. Select the scaled groups or components.
  2. Start Scale Definition (Extensions › ARQO for SketchUp); it runs in the Smart Scale panel.
  3. If the component is shared, choose Selected only or All copies in the question box.
  4. Read the result in the panel. The panel's Bake scale into definition button does the same.

Good to know

  • Every placement of a changed definition keeps its size: it takes the inverse scale.
  • By default only the selected copies are separated and changed; all copies only when you choose so.
  • If the selection is already at scale 1, nothing changes; scaled copies one level inside are counted: open it and select them.
  • Copies in the selection that are already unscaled are left and counted.
  • Locked objects are skipped. One Undo removes it; Cancel in the question changes nothing.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
