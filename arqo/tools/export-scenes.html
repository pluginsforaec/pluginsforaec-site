Export Scenes

Pick a folder, the size and PNG or JPG: every scene (or the current one) is written as a numbered, safely named image at that size; the scene shown before is shown again. Nothing in the model changes.

How to use it

  1. Click Export Scenes (toolbar, or Extensions › ARQO for SketchUp › OUTPUT).
  2. Choose the folder; it opens at the model's own folder.
  3. In the box, set width and height in pixels, PNG or JPG, and All scenes or This scene only.
  4. Confirm: each scene is shown and saved as 01 Scene name.png, 02 Scene name.png and so on.
  5. Read the message: how many images were written, where, and at what size.

Type in the measurements box

1920
in Width: the image width in pixels
1080
in Height: the image height in pixels

Good to know

  • Width and height are whole pixels from 16 to 16000; anything else keeps the box open and says why.
  • A file already in the folder is never overwritten: the new image gets a number, such as 01 Plan (2).png.
  • Scene transitions are switched off while exporting; afterwards the scene you were on, your own camera, tag visibility and shadow display are put back.
  • The image is what the screen shows; there is no transparent background.
  • With no scenes in the model, the current view is saved. Characters a file name cannot hold are replaced.
  • Nothing in the model changes, so there is no Undo step. The last size, format and choice are offered next time.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
