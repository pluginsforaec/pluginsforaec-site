Smart Scale

See the selection's width, depth and height in model units and type the targets; choose the anchor; scale, or stretch so height and thickness stay and nested components keep their size; this copy or every copy; two points to a distance, match another object, drag along an axis, reset and bake the scale.

How to use it

  1. Select groups, components or loose geometry and open Smart Scale (Extensions › ARQO for SketchUp); the panel shows Width, Depth, Height.
  2. Type a target in any of the three fields: 2000mm, x2, +150mm or =3000.
  3. Choose Scale, or Stretch (keep thickness); tick Keep proportions to scale all three alike.
  4. Pick the Anchor: one of nine points in plan, and Top, Middle or Bottom.
  5. For a shared component choose This one or All copies, then press Apply (or Enter in a field).
  6. Other ways: Two points…, Match to…, Drag along an axis…, Reset scale, Bake scale into definition.

Type in the measurements box

2000mm
makes that dimension 2000 mm
=3000
makes it 3000 in the model's unit
x2
twice the size (2x and 200% work too)
+150mm
150 mm longer (-150mm: shorter)
reset
Drag along an axis: removes the scale of the selected groups and components

Good to know

  • One group or component is measured in its own axes, anything else in the model's; text, dimensions and guides do not count.
  • A bare number such as 2000 is refused: type 2000mm, =2000 or x2.
  • Keep proportions takes the field that changes most for all three.
  • Turned objects are scaled along their own axes, never sheared.
  • Stretch moves the part beyond the middle: height, thickness and nested components stay; refused when an arc or circle crosses the middle.
  • This one is the default every time; All copies writes the definition and asks first. Stretching one shared copy makes it unique.
  • Keep nested components' size applies when All copies is chosen.
  • Locked objects are skipped and counted; a component whose definition forbids scaling on an axis is refused.
  • Each action is one Undo. The panel follows the selection.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
