Model Journal

Run Model Journal: every ARQO run in the model is listed newest first — when it ran, with which tool and version, and how many things it left in the model (each counted once, however many copies of its component are placed). Choose one in the box and what it made is selected. A CSV of every run is written beside the model. Nothing in the model changes, and no person's name is ever stored: models travel.

Pictures and a short film of Model Journal at work come here.

How to use it

  1. Click Model Journal.
  2. The box lists the runs, newest first: when, which tool, how many things.
  3. Choose one: what it made is selected.
  4. A CSV of every run is written beside the model.

Good to know

  • Things are counted once, however many copies of their component are placed.
  • No person's name is stored in the model.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
