Explode

Explode groups and components through every nesting level in one step, or flatten only what is nested inside them; images become textured faces and, if asked, curves become plain edges. Locked containers are kept.

How to use it

  1. Select groups, components or images.
  2. Right-click › ARQO and choose Explode: every level, Explode: flatten inside or Explode: one level (also under Extensions › ARQO for SketchUp › COMPONENTS).
  3. Or click the toolbar button: it runs the scope set in Extensions › ARQO for SketchUp › Settings › Explode… (every level by default).
  4. With flatten inside on a component placed more than once, choose Selected only or All copies when asked.
  5. Read the message: the scope that ran and what was exploded.

Good to know

  • Every level: the selected groups and components and everything nested in them become loose geometry in the current context.
  • Flatten inside: the selected containers stay, and everything nested inside is merged into them. Only the selected copies of a shared component change unless you choose all copies.
  • Every level and one level explode the selected copies only; the other copies of a component do not change.
  • Selected images become textured faces.
  • Setting Curves and arcs: Keep (default) or Split into edges, which turns curves and arcs in the result, and selected curve edges, into plain edges.
  • Locked groups and components are never opened; they are kept and counted. One Undo restores everything.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
