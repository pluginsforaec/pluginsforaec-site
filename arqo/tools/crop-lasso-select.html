Crop / Lasso Select

Drag a lasso or click the corners of a polygon and press Enter; take only what is wholly inside or anything touched (Tab); Shift adds, Ctrl removes. Faces, edges, groups and components of the current context.

How to use it

  1. Start Crop / Lasso Select (Extensions › ARQO for SketchUp).
  2. Drag round the things for a lasso, or click polygon corners and press Enter or double-click.
  3. Press Tab (or use the card) to switch Inside and Crossing.
  4. Hold Ctrl to add, Shift to add or remove, Ctrl+Shift to remove; no key replaces the selection.
  5. The preview shows what would be taken; the tool ends when the shape closes.

Keys

Tab
Inside (only things wholly inside) / Crossing (anything the shape touches)
Ctrl
hold: add to the selection
Shift
hold: add or remove (toggle)
Ctrl+Shift
hold: remove from the selection
Enter
close the polygon and select
Esc
clear the shape; with no shape, leave the tool

Good to know

  • Takes visible faces, edges, groups and components of the open context; hidden tags and what is behind the eye are never taken.
  • Judged by the geometry, not by bounding boxes.
  • A press becomes a lasso only once the mouse moves; a polygon needs at least three corners.
  • Selecting is not an Undo step: the model is not changed.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
