Connect / Heal

Close the small gaps between open edge ends, within a gap limit you set.

How to use it

  1. Select the edges with gaps; if they are inside a group, open it first.
  2. Run Connect / Heal (Extensions › ARQO for SketchUp).
  3. Read the message: how many gaps were closed, which were left and why.
  4. For larger gaps, raise Gap limit (mm) in Extensions › ARQO for SketchUp › Settings › Connect / Heal…, then run again.

Good to know

  • Only ends closer than the gap limit (25 mm by default) are joined, nearest first; each open end is used once.
  • Nothing existing is moved or deleted; one Undo removes every new edge.
  • Closed groups and components in the selection are not entered; ends in different groups are not joined.
  • Open ends with no other end nearby stay open and are counted.
  • If no gap is closed, the message says why and the model is unchanged.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
