To Components+

One click turns selected groups into components, and groups holding the same geometry become instances of one definition at their own placement; loose faces and edges become one component or one per face. Names from a prefix or the group's own.

How to use it

  1. Select groups and/or loose faces and edges.
  2. Run To Components+.
  3. Read the report: groups converted, how many share a definition, components made from loose geometry.
  4. To change the behaviour, open Extensions › ARQO for SketchUp › Settings › To Components+….

Good to know

  • Groups with the same geometry (the same points, not only the same lengths) share one definition, each at its own place; set Alike groups to separate to convert each on its own.
  • Loose geometry becomes one component, or one per face with its edges when Loose geometry is set to each.
  • Definitions are named from the prefix (Part 1, Part 2…); a group's own name is kept.
  • A converted group keeps its tag, material and attributes.
  • Selected components are left as they are; locked groups are kept and counted. One Undo restores everything.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
