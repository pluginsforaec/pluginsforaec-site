Import DXF

Text DXF import; targets dynamic blocks, mline, ellipse, spline, polyline, circle, arc, line and text.

How to use it

  1. Start Import DXF and choose the .dxf file.
  2. Under The drawing's unit, keep the file's own unit or choose mm, cm, m, in or ft.
  3. Under Where it goes, choose lower left corner at the origin, or its real coordinates.
  4. Confirm; the drawing comes in as one group named DXF and the file name.

Good to know

  • Lines, polylines (with their arcs), circles, arcs, ellipses, splines, the centre line of multilines, text and block references are drawn.
  • Circles and arcs come in as true SketchUp circles and arcs; blocks become components.
  • Layers become tags.
  • A file with no unit is read as mm. A file's unit is not always right: check the size and choose the unit by hand if needed.
  • When moved to the origin, the shift is given in the message and written on the group. Your last placement choice is remembered.
  • Other entity types are not drawn; the message counts them.
  • A binary DXF is refused: save it from CAD as ASCII DXF. Nothing is drawn.
  • One Undo takes the whole import back.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
