Model Doctor

One panel looks the whole model over: reversed faces, duplicates lying on each other, holes in solids, empty objects, tiny edges, objects far from the model, and unused components, materials and tags. Show selects what holds each finding and brings it into view; Fix mends it, Fix all mends everything that can be mended — each one Undo. Looking changes nothing.

How to use it

  1. Start Model Doctor: the panel opens on a scan of the whole model; each row says what it found.
  2. Press Show on a row: what holds the finding is selected and brought into view.
  3. Press Fix on a row to mend it, or Fix all to mend everything that can be mended.
  4. Press Scan again after you change the model by hand.

Keys

Esc
Close the panel

Good to know

  • Looking changes nothing in the model: the scan writes no geometry, tag, material or Undo step.
  • Reversed faces are counted only where it is certain: in closed shapes, and a lone level face with its back up. An open shape of several faces is left as you made it.
  • A hole is a flat closed loop of edges with a face on one side only, in a 3D shape; Fix closes it and turns the new face outwards.
  • Tiny edges (1 mm or less) and far objects (more than a kilometre from the model) are only shown: what they were meant to be is yours to say.
  • Each Fix and Fix all is one Undo. A component is mended in its definition, so every copy is; locked objects are left alone.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
