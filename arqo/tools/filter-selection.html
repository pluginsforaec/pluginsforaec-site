Filter Selection

See what is selected broken down by kind, face orientation, edge type, tag and material, then keep only what you ticked or take it out. Restore brings back the selection before the last filter.

How to use it

  1. Select something, then click Filter Selection (toolbar, or Extensions › ARQO for SketchUp › SELECTION) to open the panel.
  2. Under Kind, tick types (Edges, Faces, Groups…); none ticked means all. Faces and Edges get sub-ticks for orientation and edge type.
  3. Tick tags and materials if needed, and set Visibility to Any, Visible or Hidden.
  4. Check the count (n of total match), then click Keep only these or Remove these.
  5. Click Restore to bring back the selection before the last Keep or Remove; Clear filters resets the ticks.

Keys

Enter
Keep only these (when no button or field has focus)
Esc
close the panel

Good to know

  • Within one group any tick matches; groups combine (kind and tag and material…). A group with nothing ticked does not filter.
  • Faces: Horizontal, Vertical, Sloped. Edges: Straight, Arcs and curves, Soft / smooth.
  • Materials are read only on edges, faces, groups and components. Hidden means hidden itself or on a hidden tag.
  • The panel follows the selection, so you can narrow it step by step.
  • Selecting is not an Undo step in SketchUp, so Restore is the way back. The model itself is not changed.
  • Ticked kinds, edge and face types and visibility are remembered; tags and materials belong to one model and are not.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
