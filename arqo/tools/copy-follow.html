Copy Follow

Select the source, click the object it belongs to: every other instance of that component gets a copy at the same relative place, or click the targets one by one and press Enter. Turned and moved targets get turned and moved copies.

How to use it

  1. Select the groups or components to copy (the handle), then start Copy Follow (Extensions › ARQO for SketchUp).
  2. Click the object they belong to (the door).
  3. If that object is a component with other copies, each of them gets a copy at once.
  4. Otherwise click the targets one by one (click again to drop one) and press Enter.
  5. Or type all to use every copy of the reference's component.

Keys

Enter
copy to the clicked targets
Esc
clear the reference and targets; again: leave the tool

Type in the measurements box

all
every other copy of the reference's component in this context becomes a target

Good to know

  • To choose targets yourself even for components, set Targets to pick in Extensions › ARQO for SketchUp › Settings › Copy Follow….
  • The source stays; copies keep everything the source carries, attributes (dynamic and IFC ones too) included.
  • On a scaled target the copy goes to the matching place but keeps its own size; turned or mirrored targets turn it too.
  • A copy already standing in place is not made again.
  • Only groups and components follow; loose faces and edges in the selection are not copied and are counted.
  • Placement is read from the geometry: text or dimensions inside do not shift it.
  • Locked targets are skipped and counted. One Undo removes all the copies.

Always

  • One Undo takes the whole action back.
  • Shared components: you choose this copy or all copies.
  • The result is told in plain words; a refusal changes nothing.
