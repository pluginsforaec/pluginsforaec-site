Plugins for AEC: what they are and how to choose them

AEC stands for architecture, engineering and construction. Plugins for AEC add the tools these jobs need to the software the office already uses: SketchUp, AutoCAD, Rhino, Grasshopper.

What a plugin for AEC is

A plugin is a small program that runs inside a host application and adds commands to it. In AEC work the host is usually a modelling or drawing program, and the plugin takes over a task that is slow or easy to get wrong by hand: walls and stairs, cuts and sections, cleaning up imported drawings, scenes for a presentation.

A plugin does not replace the software. The model stays a normal SketchUp, AutoCAD or Rhino file that colleagues and consultants can open without it.

What a good plugin promises

  • Every action can be taken back: one Undo undoes the whole step, not twenty small ones.
  • It changes only what you picked. Shared components, other layers and the rest of the model stay as they were.
  • It tells you what it did, and when it cannot help, it says why and changes nothing.
  • It works the way the host works: the same keys, the same inference, typed values in the measurements box.
  • It says which versions of the host it supports, and every release lists its changes.

How to choose

Start from the task, not the plugin. Write down the three jobs that cost the office the most time in a week, then look for tools that do those jobs in your own software. Try them on a copy of a real project, not a demo file, and check the promises above: undo, safety, plain messages.

Fewer, consistent tools beat many unrelated ones. Tools that share one toolbar, one way of typing values and one set of keys are learned once.

PluginsForAEC

PluginsForAEC builds plugins for AEC on one shared foundation. The first product is ARQO for SketchUp: forty modelling tools and ARQOPush, a push/pull engine with twelve modes, on one toolbar. CADPILOT for AutoCAD, RHINOPILOT for Rhino and GH Tools for Grasshopper are on the roadmap.
